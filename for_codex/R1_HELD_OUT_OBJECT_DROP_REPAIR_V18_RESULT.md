# R1 6モジュール物体落下2件の修正結果 v18

## 結論

v16で物体落下した6モジュール機体`58a5c015f4db`の格子点0・26を、同じ物体、
支持台、機体構造、把持点および合否基準のまま再実行し、2/2成功した。

- 格子点0: 4096制御周期、最終段階8、成功。
- 格子点26: 4100制御周期、最終段階8、成功。
- 2件合計: 物体落下0、硬い衝突0、推力配分不能0、時間切れ0、安全不合格0、
  代替制御0。

## 採用した修正

- 接触割当順の追加押し込みを17 mm、23 mmとした。
- 把持全体を物体座標の+Y方向へ30 mm移した。
- 持ち上げ時間を3倍にし、持ち上げ生成高さを300 mmから30 mmへ縮めた。
- π_Lの学習済み動作量は適用せず、QPID/QPと局所サーボを使用した。

同じ押し込み量では把持面間の機構差により保持力が偏った。10/30 mmまで差を広げると
落下は止まったが物体が約30度傾いたため、最終値では差を6 mmへ縮めた。持ち上げ高さは
物体を支持台から離すために必要な範囲へ限定した。
