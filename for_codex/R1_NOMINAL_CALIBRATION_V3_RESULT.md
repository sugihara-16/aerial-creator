# R1名目制御較正v3 結果

## 結論

R1名目制御較正v3は不合格である。最小の第1段階（物体位置を基準から前後・
左右へ最大10 mm、向きを最大5度変更）で、極端な機体姿勢を通らないという
格子点100%合格条件を満たせなかった。採用範囲はない。教師軌道の正式収集と
学習は許可しない。

このv3では、関節を可動範囲の端から1%内側へ収めたうえで、把持点のずれを
三次元距離30 mm以内まで許容した。30 mmは各座標軸ごとの許容値ではない。

正式な機械可読目録は
`for_codex/R1_NOMINAL_CALIBRATION_V3_RESULT_LEDGER.json`、SHA-256は
`a967b68f06ac58265fc526e41b6d255edd82ae2bb9a53d3c91843bb6a2917264`である。

## 実行した順序

1. 決定論的な教師軌道と逆運動学で、把持姿勢までの軌道を生成した。
2. 関節可動範囲の端から1%内側へ収め、把持点の三次元距離30 mm以内、
   姿勢差0.10 rad以内で別解を求めた。
3. Isaac、制御器、再度の逆運動学、重い軌道最適化を使わず、軌道を完全追従
   したと仮定して、物体・支持台・自己衝突、関節限界、関節速度、機体の
   極端な傾き、把持姿勢到達を一次判定した。
4. 格子点100%条件を達成できないことが確定した時点で新規計算を停止した。
5. 一次判定を通過した段階だけに行うIsaac試験は、契約どおり起動しなかった。

第1段階の計画総数は682件で、一次判定を実行したのは61件、合格60件、
不合格1件である。残り621件は決定的な格子点不合格後に実行していない。
正式Isaac試験は0件である。第2～第4段階と、判定に使っていない14機体での
最終確認も実行していない。

## 不合格の根拠

不合格は4モジュール機 `train-000016-a9b26f370bba` の格子点1件である。
物体位置を前後・左右へそれぞれ−10 mm、向きは基準値のままとした条件で、
機体の最大傾きが1.5991 rad（約91.6度）となり、上限1.0472 rad（60度）を
超えた。

この軌道は把持姿勢へ到達し、最終接触数2、正規化した最小関節余裕
`0.010000000999999994`、衝突違反0、最小衝突余裕約4.81 mm、最大関節速度
約0.274 rad/sだった。したがって不合格理由は、把持点の30 mm条件、関節余裕、
衝突、関節速度ではなく、ユーザー指定の一次選別対象である極端な姿勢である。

合格60件では、正規化した最小関節余裕は同じく1%以上、衝突違反0、最小衝突
余裕約4.80 mm、最大機体傾き約1.029 radであった。軽量検査中にIsaacまたは
制御層を起動した記録はない。

## 制御経路と保護状態

今回の正式試験契約は、軽量検査合格後に、名目押し込み、QPID/QP、局所サーボ、
Isaacを使う。π_Lの仕組みと保護済みチェックポイントは保持するが、π_L由来の
動作量は適用しない。第1段階が軽量検査で不合格になったため、この制御経路を
今回の正式候補へ適用していない。

C3 promoted update 18のチェックポイント、保護済み実行器、学習工程設定、
release ledgerは変更していない。チェックポイントのSHA-256は引き続き
`6ea412ccdfe983cb2b030b3514bc8982424522673b49def188d547120984357b`である。

## 次の入口

次は教師軌道収集や学習開始ではない。不合格4モジュール機について、どの軌道
区間・機体部位が約91.6度の傾きを生んだかを読み取り、教師軌道または逆運動学の
姿勢選択で回避できるかを診断する。60度上限を緩める判断は今回の結果から自動的
には行わず、別の設計判断と承認を必要とする。
