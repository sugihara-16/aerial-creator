# R1名目制御較正v2 結果

## 結論

R1名目制御較正v2は不合格である。最小の第1段階（物体位置を基準から前後・
左右へ最大10 mm、向きを最大5度変更）で、格子点100%合格条件を満たせなかった。
採用範囲はない。教師軌道の正式収集と学習は許可しない。

正式な機械可読目録は
`for_codex/R1_NOMINAL_CALIBRATION_V2_RESULT_LEDGER.json`、SHA-256は
`09fa797d7be267a59266c1df0258127a6723042855eb54b9a85a3b1ef8f07a4a`である。

## 実行した順序

1. 決定論的教師軌道と決定論的IKで、把持姿勢までの軌道を生成した。
2. Isaac、制御器、再IK、軌道最適化を使わず、軌道を完全追従したと仮定して、
   衝突、関節限界、関節速度、極端な姿勢、把持姿勢到達を一次判定した。
3. 22機体の最外側格子点を先に横断し、格子点100%条件を達成できないことが
   確定した時点で停止した。
4. 第1段階の正式Isaac試験、第2～第4段階、未使用14機体による最終確認は
   実行していない。

第1段階の計画総数は682件で、一次判定を実行したのは24件、合格22件、
不合格2件である。この24件には22機体すべての最外側格子点が含まれる。
正式Isaac試験は0件である。

## 不合格の根拠

不合格2件はいずれも物体衝突や自己干渉ではなく、関節限界からの必須余裕
1%を満たさなかった。

- 5モジュール機 `train-000003-3b95da871f01`: 正規化した最小関節余裕
  `8.268757739461376e-07`。衝突違反0、最小衝突余裕約4.84 mm、把持姿勢到達。
- 7モジュール機 `train-000026-a8ced2acf24c`: 正規化した最小関節余裕`0.0`。
  衝突違反0、最小衝突余裕約4.80 mm、把持姿勢到達。

両方とも物体位置を前後・左右へそれぞれ−10 mm、向きを−5度変更した同じ
最外側格子点である。

## 制御経路の接続確認

正式選定の前に、別扱いの接続確認として2モジュール機の1候補を2回Isaacで
再生した。経路は、決定論的教師軌道、決定論的IK、形態対応の名目押し込み、
QPID/QP、局所サーボ、Isaacである。2/2成功、安全停止0、代替制御0だった。

この接続確認では、π_Lの仕組みと保護済みチェックポイントを保持したまま、
π_L由来の関節補正、接触補正、全体運動補正、残差力・トルクを適用していない。
記録された6種類のπ_L動作量は全時刻で厳密に0だった。この2件は実行経路の
確認専用であり、較正合格、C3昇格、学習、教師データ収集の根拠には使わない。

## 保護状態と次の入口

C3 promoted update 18のチェックポイント、保護済み実行器、学習工程設定、
release ledgerは変更していない。π_Lはシステムとして保持するが、今回のR1
標準経路には適用していない。

次は教師軌道収集ではない。まず、5モジュール機と7モジュール機で最外側点の

自動的には行わず、別の設計判断と承認を必要とする。
